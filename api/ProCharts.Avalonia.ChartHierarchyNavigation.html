Remarks

Double-click a branch to enter it, Backspace or Alt+Left to return, and Home to reset. The default is disabled. Matrix projections are not navigable. Stale displayed roots are rejected. Programmatic methods do not require enabling gestures; custom sources implement IChartHierarchyNavigator.
