CreateTreemap(ChartHierarchySnapshot, double, double, double, double)

Lays out positive-weight nodes using squarified rows, preserving a header for branches. With zero gap/header the leaf areas partition the input rectangle proportionally to weight. Zero-area nodes are omitted; parents precede their children in drawing order.
