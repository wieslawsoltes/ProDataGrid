Remarks

Results keep the input point count and owned X coordinates. Null/non-finite observations reset each calculation and its warmup; they are never silently bridged or treated as zero. Input collections must remain stable during a call. Output collections are read-only. Algorithms run in O(n) time, including periodic rolling-statistic rebasing; working windows use O(period) memory in addition to the input normalization and output arrays.

Computes Wilder ATR from high/low/close channels. The first bar in each finite run uses high-low; later bars also consider distances from the preceding close. A complete period of true ranges seeds the first average. Finite inverted high/low pairs are rejected.
