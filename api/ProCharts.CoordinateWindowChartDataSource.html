Remarks

Compose with CoalescingChartDataSource for worker-to-consumer delivery. This adapter does not own its source, create a scheduler or set renderer axes. Configure a numeric/date/log category axis for proportional Scatter X. Request WindowStart/WindowCount select an ordinal subwindow WITHIN the coordinate-filtered, neighbor-expanded rows; MaxPoints is then applied through the source's existing shared-index selector. The underlying source lock covers resolution and capture, with no temporary full-history snapshot, second data copy or request allocation.

Remarks

Returned WindowStart is relative to the source's retained history, not the coordinate view. Identities belong to this exact snapshot/session. Capture reuses the source's single-entry cache; another consumer can replace that cache without changing existing views. Source storage and per-series soft-budget conventions are unchanged.

Dispose()

Detaches notifications and releases references without clearing or disposing the underlying stream.

public void Dispose()

Remarks

Idempotent. Reads/subscriptions/policy access after disposal fail; removing a handler is still safe. In-flight reads or already captured subscriber invocations may finish; Dispose does not wait for them. Deterministically dispose the model, outer delivery adapter and this adapter in that order.
