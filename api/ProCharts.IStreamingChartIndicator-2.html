A reusable, single-writer indicator retaining algorithm-specific recurrence or bounded-window state.

public interface IStreamingChartIndicator<in TInput, out TOutput>

Type Parameters

TInput

One observation, including any required channels.

TOutput

The aligned result for the most recently consumed observation.

Remarks

Implementations are not thread-safe. Push observations in source order and serialize access. A gap consumes one observation and restarts warmup; Reset also clears the lifetime counter. Correcting an earlier observation requires Reset and replay, not another Push at that position.
