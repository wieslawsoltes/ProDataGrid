Remarks

The first bar in each finite run uses high-low; later bars include distances from the preceding close. A complete period of true ranges seeds the SMA, followed by alpha 1/period smoothing. Missing/non-finite channels restart warmup. Inverted finite high/low pairs throw before changing any state. Conventions match ChartIndicators.AverageTrueRange. Instances are single-writer.
