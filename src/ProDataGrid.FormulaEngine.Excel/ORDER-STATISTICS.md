# Order statistics

`PERCENTILE.EXC` and `QUARTILE.EXC` are registered alongside the existing inclusive functions. Exclusive percentiles map to zero-based position `(n + 1) * k - 1`; requests outside the sample's interpolatable range return `#NUM!`. Quartile arguments are truncated and must select 1, 2 or 3. Nonfinite ranks, percentile parameters and numeric sample values are rejected before integer conversion or selection.

`MEDIAN`, `LARGE`, `SMALL`, `PERCENTILE.INC`, `QUARTILE.INC`, and the exclusive functions share a private numeric snapshot and order-statistic selection. Inputs up to 128 numeric values use stack storage. Larger inputs use growable pooled numeric buffers; populated spans are cleared before buffers are returned, including error and exception paths. Source arrays and masks are never reordered or overwritten. Pool reuse reduces steady-state managed allocations, not the O(n) memory needed to store the sample.

Selection uses median-of-three pivots and three-way partitioning for repeated values. A logarithmic partition budget falls back to the runtime's introspective sort, avoiding unbounded quadratic partitioning. Minimum/maximum endpoints use linear scans. Interpolation needs only the selected element and a scan for its neighbor, rather than sorting the whole input. Median and percentile interpolation avoid intermediate overflow for finite large and opposite-sign values.

Existing scalar/array coercion conventions are retained: direct numeric text and booleans may be coerced; array text, booleans and absent positions are skipped; array errors propagate. Single-cell reference provenance and every native Excel coercion edge remain separate qualification work. Fractional LARGE/SMALL ranks retain integer truncation; bounds and nonfinite checks occur before conversion. Large inputs still need a numeric snapshot and are not covered by a new whole-workbook quota.

Regression tests compare selection with independently sorted random, ordered, reverse-ordered, organ-pipe and duplicate-heavy arrays. They cover tiny samples, exclusive endpoints, overflow-safe interpolation, sparse ownership, pool error paths, concurrent calls and warm allocation counts. The retained function benchmark includes unsorted 100,000-value median, LARGE and percentile cases; input creation and oracle sorting are outside measured regions. This is not native Microsoft Excel differential certification or a claim of universal performance parity.
