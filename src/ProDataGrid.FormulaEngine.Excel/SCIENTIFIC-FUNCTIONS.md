# Scientific and combinatorial functions

The registry implements 32 additional names: `SIN`, `COS`, `TAN`, `COT`, `SEC`, `CSC`, `ASIN`, `ACOS`, `ATAN`, `ACOT`, `ATAN2`, `SINH`, `COSH`, `TANH`, `COTH`, `SECH`, `CSCH`, `ASINH`, `ACOSH`, `ATANH`, `ACOTH`, `DEGREES`, `RADIANS`, `SQRTPI`, `FACT`, `FACTDOUBLE`, `COMBIN`, `PERMUT`, `PERMUTATIONA`, `QUOTIENT`, `EVEN`, and `ODD`.

Scalar math uses eager invocation and shares readonly scalar-argument views with the existing omission-aware text layer. Inputs may be scalars, equal-shaped arrays, or singleton rows/columns to broadcast. Arrays are newly owned results; masks and source values are not mutated. `MaximumArrayCellCount` is checked before output allocation. Scalar errors propagate per cell; invalid domains and nonfinite numeric inputs/results return formula errors.

Trigonometric arguments are radians. `ATAN2(x,y)` follows Excel's argument order, not the runtime's reversed order; the origin returns `#DIV/0!`. `ACOT` uses the principal range zero through pi. Zero poles in `COT`, `CSC`, `COTH`, and `CSCH` return `#DIV/0!`. The six reciprocal trigonometric/hyperbolic functions reject magnitudes at or above 2^27, following their documented bounds. Reciprocal hyperbolic tails and `SQRTPI` avoid avoidable intermediate overflow. Runtime math provides transcendental evaluation; bit-for-bit identity with native Excel across every platform is not certified.

Combinatorial inputs are truncated after rejecting negative values. Factorials and permutations reject guaranteed overflow before loops. Combinations use symmetry and multiplicative ratios, not factorial intermediates. Large combinations are binary64 approximations, not exact integer outputs; exact-integer test oracles are compared within explicit relative tolerances. `PERMUTATIONA` permits replacement; `QUOTIENT` truncates toward zero and checks division by zero. `EVEN`/`ODD` round away from zero; beyond 2^53, binary64 cannot represent every consecutive integer and the input is retained.

The companion precision correction removes the old absolute 1e-9 integer-snap threshold that erased small nonzero values. Configured significant-digit normalization still applies to inputs/results. This is not exact decimal arithmetic, workbook-format qualification, or complete Excel function parity.

Tests cover compiled/interpreted execution, formatter round trips, precision enabled/disabled, finite/nonfinite bounds, array broadcasting and masks, allocation checks, exact-integer combinatorics oracles, and seeded trigonometric identities. The retained `tools/formula-function-benchmarks` harness adds science smoke assertions, direct-array versus MAP sine workloads and large order-statistic baselines. Input generation and oracle sorting are excluded from measurements; result allocation and formula evaluation are included.
